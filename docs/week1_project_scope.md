# Week 1 Project Scope

| Field | Project Scope |
|---|---|
| Project Name | UTM Library Services Assistant — A Document-Grounded AI Assistant |
| Domain | Higher Education / University Library Services |
| Problem Statement | UTM students seeking library information may need to consult several official pages about membership, borrowing, renewal, and library rules. Questions that combine several conditions may require students to bring information together from different sections. This project proposes an AI assistant that understands natural-language questions, retrieves relevant official information, and provides concise answers with source references. Its usefulness will be tested against a keyword-search baseline. |
| Evidence of the Problem | Evidence 1: UTM publishes membership information and library rules on separate official pages. This demonstrates that relevant information is distributed across multiple sources.<br>Sources: UTM Library, [Library Membership](https://library.utm.my/how-to-become-a-member/) and [Library Rules and Etiquette](https://library.utm.my/general-regulations/).<br><br>Evidence 2: The official FAQ includes questions about borrowing, renewal, and membership, and directs users to additional pages for some details. This provides a starting set of information needs for the project.<br>Source: UTM Library, [Library FAQs](https://library.utm.my/libfaq/). |
| Initial Related Work (at least 3) | 1. UTM Library FAQs — existing solution. Provides predefined questions, answers, and FAQ search.<br>Source: [UTM Library FAQs](https://library.utm.my/libfaq/).<br>Key limitation: Users must identify relevant entries and combine information themselves when their question covers several topics. This is an initial assessment of the reviewed page.<br><br>2. Lewis et al. (2020), Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks. Combines document retrieval with language generation.<br>Source: [Lewis et al. (2020)](https://arxiv.org/abs/2005.11401).<br>Key limitation for this project: Its general QA results do not establish performance on UTM library information; local data preparation and evaluation are still needed.<br><br>3. Asai et al. (2022), Evidentiality-guided Generation for Knowledge-Intensive NLP Tasks. Investigates whether retrieved passages contain evidence supporting an answer.<br>Source: [Asai et al. (2022)](https://arxiv.org/abs/2112.08688).<br>Key limitation for this project: Its training-based method adds implementation work beyond a basic semester prototype. The project will instead apply the principle through evidence checks and evaluation of unsupported answers. |
| Engineering Gap / Limitation | The reviewed FAQ provides useful information, but students still need to locate relevant entries and combine conditions across sources. The practical engineering gap is to build and evaluate a small conversational interface that retrieves relevant evidence, provides traceable answers, asks for clarification when needed, and avoids unsupported answers. Whether it improves on keyword search remains an evaluation question. |
| Initial Project Objectives (2–3) | O1: To design a document-grounded question-answering assistant for UTM undergraduate students using selected public library documents.<br>O2: To develop the assistant with retrieval-augmented generation, source references, clarification prompts, and fallback responses for unsupported questions.<br>O3: To evaluate answer correctness, evidence support, handling of ambiguous and unsupported questions, and response time using a predefined test set, with keyword search as a baseline. |
| Target Users | UTM undergraduate students, especially new students seeking general information about library membership, borrowing, renewal, and library rules. |
| Data Sources (at least 2) | Source 1: [UTM Library FAQs](https://library.utm.my/libfaq/)<br>Source 2: [UTM Library Membership](https://library.utm.my/how-to-become-a-member/)<br>Source 3: [UTM Library Rules and Etiquette](https://library.utm.my/general-regulations/) |
| Similar to EduAdvisor | Both systems support university students through document-grounded question answering. Both use official information, retrieval, source references, and guardrails, and can be evaluated for answer quality, groundedness, and latency. |
| Different from EduAdvisor | EduAdvisor focuses on academic advising, including courses and graduation requirements. This project focuses on library services and rules. It provides information only and does not access student accounts, renew books, reserve materials, or make academic decisions. |
| Responsible AI Risks (at least 2) | Risk 1 — Incorrect or outdated information: An incorrect renewal answer may cause a student to miss a required action.<br>Control: Provide source references, record source dates, and flag conflicting or missing evidence.<br><br>Risk 2 — Privacy: Users may enter passwords, student IDs, or personal borrowing information.<br>Control: Do not request credentials; minimise stored query data and remove personal information from evaluation records.<br><br>Risk 3 — Misleading capability claims: Users may assume the assistant has renewed or reserved a book.<br>Control: Clearly state that it provides instructions only and direct users to the official service. |
