# Week 1 Project Scope

| Field | Project Scope |
|---|---|
| Project Name | UTM Library Services Assistant — A Document-Grounded AI Assistant |
| Domain | Higher Education / University Library Services |
| Problem Statement | UTM students seeking library information may need to consult several official pages about membership, borrowing, renewal, and library rules. Questions that combine several conditions may require students to bring information together from different sections. This project proposes an AI assistant that understands natural-language questions, retrieves relevant official information, and provides concise answers with source references. Its usefulness will be tested against a keyword-search baseline. |
| Evidence of the Problem | Evidence 1: UTM Library publishes membership information and library rules on separate official pages. The membership page explains account activation; the rules and etiquette page describes user responsibilities. This shows that relevant information is distributed across sources.<br>Sources: UTM Library Membership and UTM Library Rules and Etiquette.<br>Evidence 2: The official UTM Library FAQ contains questions in categories including General, Services, Facilities and Collection. Some answers refer readers to other official resources. These published questions provide an initial set of information needs for the project.<br>Source: UTM Library FAQs. |
| Initial Related Work (at least 3) | **1. UTM Library FAQs — existing service**<br>The official FAQ provides predefined answers, category browsing and search. It is the project’s existing-service comparison and a source of representative library questions.<br>**Source:** [UTM Library FAQs](https://library.utm.my/libfaq/)<br>**Key limitation for this project:** A question covering several topics or conditions may require users to locate and combine multiple entries. This is an assessment of the FAQ structure, not measured evidence of poor user experience.<br><br>**2. Lewis et al. (2020), Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks**<br>The study combines retrieval and generation. It provides the technical basis for retrieving relevant library information before composing an answer.<br>**Source:** [Lewis et al. (2020)](https://arxiv.org/abs/2005.11401)<br>**Key limitation for this project:** Its general-task results do not establish performance on UTM library information. Local source preparation and evaluation using representative questions are still required.<br><br>**3. Asai et al. (2022), Evidentiality-guided Generation for Knowledge-Intensive NLP Tasks**<br>The study examines whether retrieved passages actually contain evidence for an answer. This supports the project’s focus on evidence sufficiency and unsupported-answer handling.<br>**Source:** [Asai et al. (2022), NAACL](https://aclanthology.org/2022.naacl-main.162/)<br>**Key limitation for this project:** Reproducing its training-based method would exceed the initial prototype’s scope. The project will instead test whether cited passages support answers and use fallback responses when evidence is insufficient.<br><br>**4. Gao et al. (2023), Enabling Large Language Models to Generate Text with Citations**<br>The study introduces ALCE to evaluate generated answers with citations, including answer correctness and citation quality. It informs the project’s source-reference design and evaluation.<br>**Source:** [Gao et al. (2023), EMNLP](https://aclanthology.org/2023.emnlp-main.398/)<br>**Key limitation for this project:** Its benchmark does not establish performance on UTM library questions. The project needs a small domain-specific test set and checks that citations support each answer and its applicable conditions. |
| Engineering Gap / Limitation | Practical limitation: The official UTM Library FAQ gives useful answers, but questions that combine topics or conditions can require students to locate and combine information from several entries and pages. This project will build and evaluate a small document-grounded assistant that retrieves relevant evidence, gives source references, asks for clarification when needed, and avoids unsupported answers. Whether it improves on keyword search remains an evaluation question. |
| Initial Project Objectives (2–3) | O1: To design a document-grounded question-answering assistant for UTM undergraduate students using selected public library documents.<br>O2: To develop the assistant with retrieval-augmented generation, source references, clarification prompts, and fallback responses for unsupported questions.<br>O3: To evaluate answer correctness, evidence support, handling of ambiguous and unsupported questions, and response time using a predefined test set, with keyword search as a baseline. |
| Target Users | UTM undergraduate students, especially new students seeking general information about library membership, borrowing, renewal, and library rules. |

| Similar to EduAdvisor | Both systems support university students through document-grounded question answering. Both are designed to use official information, retrieval, source references, and guardrails, and can be evaluated for answer quality, groundedness, and latency. |
| Different from EduAdvisor | EduAdvisor focuses on academic advising, including courses and graduation requirements. This project focuses on library services and rules. It provides information only and does not access student accounts, renew books, reserve materials, or make academic decisions. |
| Responsible AI Risks (at least 2) | **Risk 1 — Incorrect or outdated information**<br>An incorrect renewal answer may cause a student to miss a required action.<br>**Control:** Provide source references, record source dates, and flag conflicting or missing evidence.<br><br>**Risk 2 — Privacy**<br>Users may enter passwords, student IDs, or personal borrowing information.<br>**Control:** Do not request credentials; minimise stored query data and remove personal information from evaluation records.<br><br>**Risk 3 — Misleading capability claims**<br>Users may assume the assistant has renewed or reserved a book.<br>**Control:** Clearly state that it provides instructions only and direct users to the official service. |
